# Vineet Tandel — Business Analysis Portfolio

A responsive, no-framework portfolio website designed for GitHub Pages.

## What is included

- Professional landing page
- Wireframe / prototype sample
- User journey map
- Process map
- Requirements and user stories sample
- Power BI dashboard portfolio recreation
- Anonymized case study
- Mobile navigation and responsive layout
- GitHub Pages-ready structure

## Before publishing

Search the files and replace:

- `https://www.linkedin.com/in/your-linkedin`
- `https://github.com/your-github-username`
- The resume button link (`href="#"`) in `index.html`

Add your resume PDF to the `assets` folder and update the resume link, for example:

```html
<a class="button button-secondary" href="assets/Vineet-Tandel-Resume.pdf">Resume</a>
```

## Publish with GitHub Pages

### Recommended method: user website

1. Create a GitHub repository named exactly:
   `YOUR-USERNAME.github.io`
2. Upload all files and folders from this package to the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Your website should be available at:
   `https://YOUR-USERNAME.github.io`

### Alternative: project repository

You may use a repository such as `business-analysis-portfolio`. The site URL will normally be:

`https://YOUR-USERNAME.github.io/business-analysis-portfolio/`

Because this package uses relative links, it works in either setup.

## Customize content

- Edit text in `index.html`
- Edit project details in the `projects` folder
- Replace preview SVG files in `assets`
- Update colors and spacing in `styles.css`

## Confidentiality checklist

Before publishing, remove or anonymize:

- Employer/client names when permission is not clear
- Internal screenshots
- Customer or employee information
- Proprietary KPIs or formulas
- Real datasets
- Internal URLs, IDs, ticket numbers or credentials

Use mock data or recreated visuals to demonstrate skills safely.
