## Replace the current GitHub Pages site

1. Extract this ZIP file.
2. In the `tandelvineet.github.io` repository, remove the old website files.
3. Upload every file and folder from this extracted package to the repository root.
4. Commit the files.
5. Wait a few minutes and open `https://tandelvineet.github.io/`.

Upload the extracted contents, not the ZIP file itself.
