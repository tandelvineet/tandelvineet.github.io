## Replace the existing GitHub Pages site

1. Download and extract this package.
2. In the existing `tandelvineet.github.io` repository, delete the old website files.
3. Upload all files and folders from this package to the repository root.
4. Commit the change. GitHub Pages will redeploy automatically.

The main page is `index.html`.
