Power BI practice concept

Retail Sales & Availability

A clean dataset, simple data model and suggested DAX measures for a Power BI practice project.

Purpose

Show how a small retail dataset could be structured for Power BI and translated into a clear management dashboard.

Files provided

  • Sales Data fact table.
  • Product and Store lookup tables.
  • Suggested DAX measures for Total Sales, Units Sold, Sales vs Target, Availability and Stockout Records.

Suggested model

Relate Product Lookup to Sales Data using Product ID, and Store Lookup to Sales Data using Store ID. Use one-to-many relationships from the lookup tables.

Important: The downloadable file is a Power BI-ready Excel dataset, not a PBIX file. The dashboard shown above is a static concept created for the portfolio.
